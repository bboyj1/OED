# OED AI-Assisted Issue Tracking Prototype

## Purpose

This prototype explores how AI can help OED maintainers and student contributors review GitHub issues more efficiently. The goal is not to automatically modify GitHub issues, assign labels, or make final decisions. The goal is to create AI-assisted summaries, suggested next steps, and maintainer review questions.

## Human Review Rule

All AI-generated suggestions must be reviewed by a human maintainer or contributor before being used. AI output should be treated as a draft, not as a final decision.

## Issue Review Template

For each OED GitHub issue, the AI-assisted review should include:

- Issue title and number
- Short summary
- Suggested next steps
- Possible risks or concerns
- Questions for maintainers
- Whether the issue may be beginner-friendly
